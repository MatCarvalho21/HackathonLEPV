A gente quer usar todas elas, mas como quantificar? Existe um material que fala sobre como deve ser o desenvolvimento de cada uma delas em cada idade? Devemos focar em uma faixa específica 0 a 12? 0 a 8? Temos que com base no formulário estimar isso. Talvez não seja uma escala de 1 a 10, mas algo como suficiente para a idade, insuficiente, muito insuficiente.
